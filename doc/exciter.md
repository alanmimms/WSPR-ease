# RF Exciter Algorithmic Detail

The WSPR-ease RF exciter utilizes a high-performance, pipelined digital
synthesis chain to generate clean RF signals using a "1-2-1" stepped
amplitude modulation scheme. This document explains the mathematical
and algorithmic implementation of this process.

## 1-2-1 Stepped Amplitude Synthesis

To minimize harmonic content (especially the 3rd harmonic), the exciter
approximates a sine wave by driving a push-pull transformer with three
amplitude levels per half-cycle: $1$, $2$, and $1$.

A full RF cycle is divided into 6 equal phase states ($60^\circ$ each):
-   **State 0 ($0^\circ-60^\circ$):** $+1$ (Push Base)
-   **State 1 ($60^\circ-120^\circ$):** $+2$ (Push Peak)
-   **State 2 ($120^\circ-180^\circ$):** $+1$ (Push Base)
-   **State 3 ($180^\circ-240^\circ$):** $-1$ (Pull Base)
-   **State 4 ($240^\circ-300^\circ$):** $-2$ (Pull Peak)
-   **State 5 ($300^\circ-360^\circ$):** $-1$ (Pull Base)

This specific stepping mathematically eliminates the 3rd harmonic
($-55$ dBc measured), significantly reducing the requirements for
analog filtering.

## Synthesis Pipeline

The synthesis operates at a **90 MHz** system clock. To achieve a **180
Msps** sample rate, the FPGA calculates two samples per clock cycle
(one for the rising edge, one for the falling edge) and outputs them
via Double Data Rate (DDR) IO buffers.

### Phase Accumulation (NCO)
A 48-bit Numerically Controlled Oscillator (NCO) maintains the current
RF phase.
-   **Input:** 48-bit Tuning Word ($TW$).
-   **Accumulation:** $Phase_{n+1} = (Phase_n + TW) \pmod{2^{48}}$.
-   **Pipelining:** To meet 90 MHz timing, the 48-bit addition is
    split into three 16-bit pipelined stages using `SB_MAC16` DSP
    macros.

### Dual-Phase Calculation
For 180 Msps DDR output, we need the phase at both the rising edge ($t$)
and the falling edge ($t + 0.5$).
-   **Rising Phase:** $Phase_{rise} = Phase[47:32]$ (Upper 16 bits).
-   **Falling Phase:** $Phase_{fall} = (Phase_{rise} + (TW[47:32] \gg 1)) \pmod{2^{16}}$.

### Phase Dithering (LCG)
To prevent "limit cycles" (periodic phase jitter), a 16-bit
pseudo-random noise value is injected into the phase before state
mapping. This is generated by a Linear Congruential Generator (LCG):
-   $LCG_{n+1} = (LCG_n \times 25173 + 13849) \pmod{2^{32}}$.
-   $Noise_{rise} = LCG[15:0]$.
-   $Noise_{fall} = \sim LCG[15:0]$.

### Phase-to-State Mapping
The phase is mapped to one of the 6 states ($0 \dots 5$):
-   $State_{rise} = \lfloor \frac{Phase_{rise} \times 6 + Noise_{rise}}{2^{16}} \rfloor$
-   $State_{fall} = \lfloor \frac{Phase_{fall} \times 6 + Noise_{fall}}{2^{16}} \rfloor$

The multiplication by 6 and noise addition are performed within
`SB_MAC16` DSP blocks. The resulting 3-bit state value determines which
of the four RF output pins are active.

## Python Pseudo-Code Representation

The following Python code simulates the FPGA synthesis logic:

```python
class ExciterSimulation:
    def __init__(self, tuning_word_48bit):
        self.tw = tuning_word_48bit
        self.phase = 0
        self.lcg = 0x12345678 # Initial seed

    def step(self):
        # 1. Update NCO Phase (90 MHz clock)
        self.phase = (self.phase + self.tw) & 0xFFFFFFFFFFFF
        
        # 2. Update PRNG (LCG)
        self.lcg = (self.lcg * 25173 + 13849) & 0xFFFFFFFF
        noise_r = self.lcg & 0xFFFF
        noise_f = (~self.lcg) & 0xFFFF
        
        # 3. Calculate Phases for DDR (Rising and Falling edges)
        ph_r = (self.phase >> 32) & 0xFFFF
        # Fall phase is ph_r + half a tuning word's increment
        ph_f = (ph_r + ((self.tw >> 33) & 0x7FFF)) & 0xFFFF
        
        # 4. Map to States (0-5)
        # Using the same formula as the DSP block (multiply by 6 and add noise)
        state_r = ((ph_r * 6) + noise_r) >> 16
        state_f = ((ph_f * 6) + noise_f) >> 16
        
        # 5. Map States to Pin Levels
        pins_r = self.state_to_pins(state_r % 6)
        pins_f = self.state_to_pins(state_f % 6)
        
        return pins_r, pins_f

    def state_to_pins(self, state):
        # Pins: (PushBase, PushPeak, PullBase, PullPeak)
        if state == 0: return (1, 0, 0, 0) # +1
        if state == 1: return (0, 1, 0, 0) # +2
        if state == 2: return (1, 0, 0, 0) # +1
        if state == 3: return (0, 0, 1, 0) # -1
        if state == 4: return (0, 0, 0, 1) # -2
        if state == 5: return (0, 0, 1, 0) # -1
        return (0, 0, 0, 0)

# Example: Generate 14.0956 MHz at 90 MHz System Clock
# Tuning Word = (Frequency / SystemClock) * 2^48
tw = int((14095600 / 90000000) * (2**48))
sim = ExciterSimulation(tw)

for _ in range(10):
    r, f = sim.step()
    print(f"Rising: {r}, Falling: {f}")
```

## Hardware Pin Mapping

The four output pins drive a push-pull transformer:
-   **PushBase / PullBase:** Connected to the outer taps of the
    primary winding (level 1).
-   **PushPeak / PullPeak:** Connected to a lower-impedance tap or
    driven with higher current (level 2).

By alternating between Push and Pull sides, the transformer generates
the full stepped sine wave.
